# Project brief

Build a compact, visually distinctive WordPress website for Janne Vuorela's seven locally running Windows PowerShell tools. Publish at https://jvuorela.com on IONOS WordPress Start. Develop it throughout in its own **public, open-source GitHub repository** and leave the complete final source, public deployment materials and reproducible asset derivatives there.

## Scope

Home, seven root-level tool pages, Impressum, privacy information and a genuine styled 404. Each tool page includes its character, purpose, three benefits, verified requirements, short quick-start and exact GitHub release/documentation links. No online tool execution, user uploads, blog, shop, login portal, forms, analytics or embedded media is requested.

One lightweight classic PHP theme, theme.json, native Pages and editable core blocks. Minimal vanilla JavaScript only where useful, locally served fonts/artwork, and no added presentation plugins or page builder. Download buttons link to verified GitHub release pages; no live GitHub API dependency. Content remains editable with the development computer off. The database is authoritative once editorial work begins.
